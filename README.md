# CipherGrit-Real-time-Ransomware-Detection-via-Hardware-Indicators
CipherGrit Real-time Ransomware Detection via Hardware Indicators

Hardware Indicators collected across 17 Ransomware Families: 
Avaddon, Babuk, BlackMatter, Conti, Dharma, Doppelpaymer, Exorcist, Gandcrab, Makop, Maze, Nefilim, Netwalker, Phobos, Pysa, Ragnarok, Ransomexx, WannaCryptor

The ransomware sample and the collected ransomware behavior CSV are available to use in the categorization of each ransomware family.
The evaluation testbed was conducted on a DELL P165G laptop equipped with a 13th Gen Intel Core i5-1335U processor, 8 GB of SODIMM Memory (3200 MT/s), and a high-speed Samsung PM9B1 NVMe 256 GB SSD (read rates of 3.3k–3.6k MB/s and write rates of 1.25k–3k MB/s) running Windows 11 Pro.
